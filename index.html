Welcome to Sticks & Stones

Before you start rolling, open Settings and set your Discord username. It is used for roll reporting so your channel log stays readable.

Tip: Use Save to keep common rolls, and use Share to generate a link that loads an expression and label.

Settings

Changes save automatically on this device.

Shortcut: press Ctrl or Cmd and comma to open Settings. Press ? to open Help.

Sound uses synthesized audio so there are no external files.

This build stores a Discord webhook in the file. Keep this file private.

Data tools

Export includes log, favorites, and initiative list. Import merges what it can.

This app stores settings in localStorage. Clearing browser data will reset everything.
